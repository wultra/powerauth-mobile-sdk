# watchOS Documentation

<!-- SIDEBAR _Sidebar_watchOS.md -->
<!-- BREADCRUMB watchOS -->

This guide explains how to integrate PowerAuth SDK into a watchOS app and connect it to its companion iOS app.

It covers installation and configuration, checking activation status, token-based authentication, synchronized time, and common tasks. The iOS guide describes the corresponding Watch Connectivity setup and how to send activation status and tokens to the watch.
